How certificates work here

  1. Vault — this page holds one TLS identity (fullchain + key), encrypted. Never shown again.
  2. This PiHerder — optional Caddy edge on this instance (./certs).
  3. Deploy targets — one per service (not the whole stack): type + path + restart. Grouped under host for scanning.
  4. Deploy — edge in-stack, or SSH write per service target.
